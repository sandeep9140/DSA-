# ⏱️ Complexity Awareness

While solving problems, special attention is given to:

```text
O(1)      Constant
O(log n)  Logarithmic
O(n)      Linear
O(n log n)
O(n²)     Quadratic
```

The goal is to understand **why an optimized solution is better**, not just its code.
